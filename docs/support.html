Technical Support

Transmission for UGOS · Developer: David Sanchez

Most questions are answered in the Help guide, including the troubleshooting section.

Report a problem or ask a question

Open an issue at github.com/emulienfou/ugos-transmission/issues. Please write in English. To help fix it quickly, include:

  1. The app version, shown in App Center (for example 4.1.4.0014).
  2. Your NAS model and UGOS Pro version.
  3. What you did, what you expected, and what happened, with any error message.
  4. The app's startup log lines that begin with [ug-entrypoint], if the problem is about permissions or folders. You can find them in the logs of the app's container in the UGOS Docker app.

Please don't post your web UI password or other private information.

Frequently asked questions

I forgot the web UI password.

In UGOS, open Control Panel and go to the app's configuration page. Set a new web UI username and password and save. The new login applies the next time the app starts.

A torrent stops with "No data found!" or "Permission denied".

The app can't write to one of its folders. See Troubleshooting.

Downloads are slow.

Forward port 51413 (TCP and UDP) on your router to the NAS, then use Test port in Settings › Network.

Is this the official Transmission app?

No. It is an unofficial package of the open-source Transmission client. For questions about Transmission itself, see transmissionbt.com.
