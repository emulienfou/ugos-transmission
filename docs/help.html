Getting started

Transmission for UGOS: a BitTorrent client for UGREEN NAS devices running UGOS Pro

1. Install

  1. In App Center, install Transmission for UGOS. The Docker app is installed automatically if you don't have it yet.
  2. Choose the Download folder: the shared folder where finished downloads are saved, for example downloads.
  3. Choose a web UI username and password. Both are required and protect the app's web page.

2. Open the app

Click the app's icon on the UGOS desktop. It opens in a new browser tab. You can also go to http://<your-NAS-IP>:9091.

The first time, you'll be asked to accept the Privacy Policy and License Agreement, then to sign in with the username and password from step 1.

3. Add a torrent

  • Click Add and paste magnet links or URLs (one per line), or choose .torrent files.
  • You can also drag a .torrent file anywhere onto the page.
  • In the Add dialog you can choose the folder inside your download folder, and whether to start downloading right away.

4. Follow and manage downloads

  • The left sidebar filters by status: all, downloading, seeding, paused, errors.
  • Click a torrent to open its details: general info, files, peers and trackers.
  • Use the toolbar to start, pause or remove torrents. Removing can also delete the downloaded files.
  • Current download and upload speeds are shown at the bottom of the sidebar.

5. Where files go

Folder (inside your download folder)What's in it
completeFinished downloads (change it in Settings › Downloading)
incomplete or incomplete-transmissionDownloads in progress, moved to complete when they finish

If your download folder already has an incomplete folder from another app that Transmission can't write to, it uses incomplete-transmission instead.

6. Settings

Open Settings with the gear icon at the bottom of the sidebar:

  • Speed: download and upload limits, and an alternative "turtle" speed with a schedule.
  • Downloading: download folder, incomplete folder, queue size.
  • Seeding: stop seeding at a ratio or after a time.
  • Privacy: encryption and blocklist.
  • Network: peer limits, µTP, PEX, DHT, Local Peer Discovery, port test.
  • Interface: theme, refresh rate, speeds in the browser tab title.
  • About: versions, links to this help, the policies and the source code.

7. Faster downloads

Forward port 51413 (TCP and UDP) on your router to your NAS. Then click Test port in Settings › Network to check it's open.

8. Use with Sonarr, Radarr and similar apps

  1. In the app's download client settings, add Transmission with your NAS IP, port 9091, and the web UI username and password.
  2. Leave Directory empty and set a Category (for example tv-sonarr). Downloads go to a subfolder with that name.
  3. If the other app sees the download folder at a different path, add a Remote Path Mapping from /downloads/ to that path.

9. Change the login

Open UGOS Control Panel and go to the app's configuration page. You can change the web UI username and password there.

10. Troubleshooting

"Permission denied" when adding a torrent

The app can't write to the download folder. In UGOS, give the app's user read/write access to that shared folder, or choose another folder. The app's log says which user it runs as (lines starting with [ug-entrypoint]).

"No data found!"

The torrent's files aren't where Transmission expects them: they were moved or deleted, or a folder couldn't be written. Restart the app, then select the torrent and choose Verify Local Data, then Start.

The sign-in keeps failing

Check the username and password you set at install. You can set new ones in Control Panel (see step 9).
